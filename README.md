# Student Placement Prediction

## Project Overview
This is a beginner-friendly Machine Learning
project that predicts student placement based
on IQ and CGPA.

## Objective
To understand how a Machine Learning
classification model learns patterns from
data and makes predictions.

## Dataset
The dataset contains 500 synthetic student
records with the following columns:
- Student_ID
- IQ
- CGPA
- Placement (0 = Not Placed, 1 = Placed)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning Workflow
1. Data Understanding
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Preprocessing
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Prediction

## Project Status
Currently in development.

## Note
This project uses synthetic data for
educational purposes only.
